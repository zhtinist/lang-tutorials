# 计算机基础 · CS Fundamentals

操作系统、网络、数据库是后端和系统类面试绕不开的三块基石,也是理解上层框架(数据库连接池、网络框架、并发模型)必须打通的底层原理。本专题把这三块拆成 7 篇,每篇聚焦一组高频考点,给出原理、结构图和可对照的具体例子,而不是名词罗列。

## 使用建议

1. **速成路线**:进程与线程 → TCP 基础 → SQL/事务/索引 → Redis。这四篇覆盖了后端面试出现频率最高的考点。
2. **系统学习**:按操作系统 → 网络 → 数据库的顺序通读,每一层都是上一层的运行环境——网络协议跑在操作系统的 I/O 模型之上,数据库的锁和 MVCC 又依赖操作系统的并发原语。
3. **重点区分类问题**:数据库锁 vs MVCC、缓存穿透 vs 击穿 vs 雪崩、TCP 拥塞控制 vs 流量控制,这几组概念最容易在面试里被混着问,读的时候留意每篇里专门给出的对比表。
4. **代码与图示**:原理性内容配 ASCII 结构图(如 B+ 树、TCP 状态机);示例 SQL 和命令直接可执行,不追求完整项目。
5. **与其他专题的关系**:架构专题讲"系统怎么切、模块怎么分",算法专题讲"单点算法怎么实现",本专题讲"操作系统/网络/数据库这几层地基本身是怎么工作的"——三者是互补关系,不是包含关系。
