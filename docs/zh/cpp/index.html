C++ 教程 · 全面速查手册

这套教程的定位和本仓库其他语言教程(python-tutorial、go-tutorial 等)不同:那几套教程假设读者已经熟悉 C/C++,聚焦”底层到底发生了什么”这种深挖式讲解;这套 C++ 教程反过来——假设你已经写过一些 C++ 代码,但知识点比较零散,需要一份全面覆盖、按知识点组织的速查手册,把 C++ 这门语言(从基础语法到 C++20)当作一份检查清单过一遍,查漏补缺。因此每一节的讲解不追求像其他教程那样深挖原理,而是优先保证知识点覆盖全、示例能编译运行、内容组织清晰、便于按需查阅。

阅读顺序(建议)

# 章节 一句话说明
01 基础语法与编译过程 四阶段编译流程、头文件与 include guard、命名空间、cin/cout、声明 vs 定义、ODR
02 变量类型与内存布局 基本类型字节数、auto/decltype、const/constexpr/volatile、引用 vs 指针、四大内存分区、struct 对齐、位域、union、枚举
03 函数与引用 重载、默认参数、inline、函数指针、lambda 捕获列表、std::function/bind、可变参数模板、传参方式选择、RVO/NRVO
04 面向对象编程 访问控制、五类构造函数、this/静态成员/friend、继承与菱形问题、vtable/vptr、抽象类、override/final
05 运算符重载与特殊成员函数 可重载运算符清单、拷贝/移动构造与赋值、Rule of Three/Five/Zero、explicit、类型转换运算符
06 模板与泛型编程 函数/类模板、全特化/偏特化、非类型模板参数、可变参数模板、SFINAE、C++20 concepts
07 ⭐ STL 容器详解 顺序容器/关联容器/无序容器的底层实现与选型(旗舰深度章节,另行编写)
08 ⭐ STL 算法与迭代器 迭代器分类、<algorithm> 常用算法、C++20 ranges(旗舰深度章节,另行编写)
09 智能指针与现代内存管理 unique_ptr/shared_ptr/weak_ptr、循环引用、自定义删除器、RAII、new/delete vs malloc/free
10 异常处理 try/catch/throw、异常类层次、自定义异常、noexcept、异常安全三等级、构造/析构中的异常
11 ⭐ 多线程与并发 std::thread、锁、条件变量、原子操作、内存序(旗舰深度章节,另行编写)
12 C++11/14/17/20 新特性汇总 按标准版本整理关键特性清单,每条配一个最小代码示例

标 ⭐ 的三章(07、08、11)是本教程的旗舰深度章节,聚焦 STL 与多线程这两个日常最高频、也最容易踩坑的领域,会以接近”其他语言教程”那种深挖原理的方式单独撰写,内容和写作节奏会比其余章节更详尽。

使用建议

  • 这不是一套需要从头读到尾的教程,更像一本按目录查找的工具书——已经掌握的章节可以跳过,只在需要的时候回来查。
  • 每章开头是知识点速览,正文按小节展开,每个知识点配一段实际编译运行过的 C++ 代码(g++ -std=c++20),不确定某个语法的行为时,直接找到对应小节复制代码本地验证。
  • 章节末尾统一是 [← 返回索引](index.html),没有强制的上一章/下一章导航——因为本教程定位是速查清单而非线性叙事,鼓励按需跳转而非顺序通读。
