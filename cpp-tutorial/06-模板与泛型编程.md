# 模板与泛型编程

本章覆盖 C++ 模板系统的核心知识点:函数模板、类模板、模板特化(全特化/偏特化)、非类型模板参数、可变参数模板、SFINAE,以及 C++20 引入的 concepts。模板是 C++ 泛型编程与"零运行时开销抽象"的基础,STL 容器/算法(第 7、8 章)全部建立在模板之上。

## 一、函数模板

```cpp
#include <iostream>

template<typename T>
T maxVal(T a, T b) { return a > b ? a : b; }

template<typename T, typename U>          // 多个模板参数,返回类型用 auto 让编译器推导公共类型
auto add(T a, U b) { return a + b; }

int main() {
    std::cout << maxVal(3, 7) << "\n";            // T 从实参推导为 int
    std::cout << maxVal(3.5, 2.5) << "\n";         // T 推导为 double
    std::cout << maxVal<double>(3, 7.5) << "\n";    // 显式指定模板参数,3 转成 double

    std::cout << add(1, 2.5) << "\n"; // int + double -> double(3.5)
}
```

```
7
3.5
7.5
3.5
```

编译器根据调用时的实参类型自动推导模板参数(模板参数推导),必要时也可以像 `maxVal<double>(...)` 一样显式指定。每一种被实际用到的类型组合,编译器都会生成一份独立的具体化代码(称为"实例化"),这是模板"零运行时开销"的来源,代价是可能增加编译时间和二进制体积。

## 二、类模板、非类型模板参数、CTAD

```cpp
#include <iostream>

template<typename T, int N = 3>              // N 是非类型模板参数(不是类型,是一个编译期常量值),带默认值
class FixedArray {
public:
    T& operator[](int i) { return data_[i]; }
    int size() const { return N; }
private:
    T data_[N]{};
};

template<typename T>
class Box {
public:
    explicit Box(T v) : value_(v) {}
    T get() const { return value_; }
private:
    T value_;
};

int main() {
    FixedArray<int> arr;          // 使用默认 N=3
    arr[0] = 10; arr[1] = 20; arr[2] = 30;
    std::cout << "size=" << arr.size() << " arr[1]=" << arr[1] << "\n";

    FixedArray<double, 5> arr2;    // 显式指定 N=5
    std::cout << "size2=" << arr2.size() << "\n";

    Box<int> b1(42);
    Box b2(3.14);                   // C++17 类模板参数推导(CTAD),无需显式写 Box<double>
    std::cout << b1.get() << " " << b2.get() << "\n";
}
```

```
size=3 arr[1]=20
size2=5
42 3.14
```

非类型模板参数常见类型:整型、枚举、指针/引用、C++20 起还支持浮点数和某些字面量类类型;`std::array<T, N>` 就是标准库里非类型模板参数的典型应用。CTAD(Class Template Argument Deduction,C++17)让 `Box b2(3.14);` 这样的写法可以省去显式模板实参,编译器从构造函数参数推导。

## 三、模板特化:全特化与偏特化

**全特化**:为某个具体类型单独提供一份实现,完全替代主模板对该类型的行为。

**偏特化**(只有类模板支持,函数模板不支持偏特化,只能通过重载模拟):为某一**类**类型(比如"所有指针类型""所有固定大小数组")提供特殊实现。

```cpp
#include <iostream>

template<typename T>
class TypeName {
public:
    static const char* name() { return "unknown"; }
};

template<>                              // 全特化:针对 int 这个具体类型
class TypeName<int> {
public:
    static const char* name() { return "int"; }
};

template<>
class TypeName<double> {
public:
    static const char* name() { return "double"; }
};

template<typename T>                    // 主模板
class Container {
public:
    static const char* describe() { return "generic container"; }
};

template<typename T>                    // 偏特化:针对“指针类型”这一类
class Container<T*> {
public:
    static const char* describe() { return "pointer container"; }
};

template<typename T, int N>              // 偏特化:针对固定大小数组 T[N]
class Container<T[N]> {
public:
    static const char* describe() { return "fixed-size array container"; }
};

int main() {
    std::cout << TypeName<int>::name() << "\n";      // int(全特化)
    std::cout << TypeName<double>::name() << "\n";    // double(全特化)
    std::cout << TypeName<char>::name() << "\n";       // unknown(走主模板)

    std::cout << Container<std::string>::describe() << "\n"; // generic container
    std::cout << Container<int*>::describe() << "\n";           // pointer container(偏特化)
    std::cout << Container<int[5]>::describe() << "\n";          // fixed-size array container(偏特化)
}
```

```
int
double
unknown
generic container
pointer container
fixed-size array container
```

编译器为一次具体的模板使用选择"最特化"且匹配的版本:全特化 > 偏特化 > 主模板。

## 四、可变参数模板(parameter pack)

可变参数模板(`typename... Args`)已在第 3 章"可变参数模板与函数"详细展开(递归展开 + C++17 折叠表达式),这里只强调它在类模板里的应用——`std::tuple`、`std::variant` 等标准库类型都是靠类模板的参数包实现的:

```cpp
template<typename... Types>
class MyTuple; // 声明一个可以容纳任意数量、任意类型元素的元组模板(标准库 std::tuple 的简化思路)
```

`sizeof...(Types)` 取参数包内类型个数,`Types...` 在需要展开的位置(基类列表、函数参数列表等)展开成逗号分隔的一串类型。

## 五、SFINAE 简介

**SFINAE**(Substitution Failure Is Not An Error,替换失败不是错误):在模板参数替换过程中,如果某个候选产生了非法的类型或表达式,编译器不会报错,只是**悄悄把这个候选从重载集合里剔除**,继续尝试其他候选。这是 C++11/14 时代实现"按类型特征选择不同实现"的核心机制,通常配合 `<type_traits>` 的 `std::enable_if` 使用:

```cpp
#include <iostream>
#include <type_traits>

template<typename T>
typename std::enable_if<std::is_integral<T>::value, std::string>::type
classify(T) { return "integral"; }

template<typename T>
typename std::enable_if<std::is_floating_point<T>::value, std::string>::type
classify(T) { return "floating point"; }

// C++17 起可以直接用 if constexpr 达到类似效果,写法更直观、更易读
template<typename T>
std::string classifyModern(T) {
    if constexpr (std::is_integral_v<T>) {
        return "integral (constexpr)";
    } else if constexpr (std::is_floating_point_v<T>) {
        return "floating point (constexpr)";
    } else {
        return "other (constexpr)";
    }
}

int main() {
    std::cout << classify(1) << "\n";        // integral
    std::cout << classify(1.5) << "\n";       // floating point

    std::cout << classifyModern(1) << "\n";
    std::cout << classifyModern(1.5) << "\n";
    std::cout << classifyModern("str") << "\n";
}
```

```
integral
floating point
integral (constexpr)
floating point (constexpr)
other (constexpr)
```

`std::enable_if` 版本的可读性较差(返回类型里嵌套 `typename ... ::type`),现代 C++(17 起)大多数场景可以用 `if constexpr` 替代——同一个函数体内根据编译期条件选择性编译分支,不满足条件的分支甚至不会被实例化,写法更接近普通的 `if/else`。SFINAE 更底层的应用(检测某个类型是否有某个成员函数/类型别名等)仍然有价值,但日常业务代码里 `if constexpr` 和 C++20 concepts 已经能覆盖绝大多数场景。

## 六、C++20 concepts 简介

concepts 给模板参数加上**语义化的约束**,取代传统 SFINAE/`enable_if` 的隐晦写法,同时报错信息更清晰、直接指出"哪个约束没满足"而不是一堆重载决议失败的噪音:

```cpp
#include <iostream>
#include <concepts>

template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;  // 自定义 concept:数值类型

Numeric auto square(Numeric auto x) { return x * x; }            // 用 concept 约束参数与返回类型

template<Numeric T>                                                // 也可以写成模板参数约束的形式
T cube(T x) { return x * x * x; }

int main() {
    std::cout << square(5) << "\n";       // 25
    std::cout << square(2.5) << "\n";      // 6.25
    std::cout << cube(3) << "\n";           // 27
}
```

```
25
6.25
27
```

违反约束时,编译器直接指出问题所在,而不是一堆晦涩的重载决议失败信息:

```cpp
square("str"); // 字符串不满足 Numeric concept
```

```
error: no matching function for call to 'square'
note: candidate template ignored: constraints not satisfied [with x:auto = const char *]
note: because 'const char *' does not satisfy 'Numeric'
note: because 'const char *' does not satisfy 'integral'
```

标准库在 `<concepts>` 里预定义了一批常用 concept:`std::integral`、`std::floating_point`、`std::same_as`、`std::convertible_to`、`std::copyable`、`std::invocable` 等;`<ranges>` 里的 range 相关 concept 见第 8 章。`concept` 关键字定义约束,`requires` 子句可以表达更复杂的多重约束(要求某类型支持某些操作、有某些成员等)。
