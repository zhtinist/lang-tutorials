# C++11/14/17/20 新特性汇总

本章按标准版本整理关键新特性清单,每条给一个最小可编译验证的代码示例。很多特性(`auto`、lambda、智能指针、移动语义、`if constexpr`、concepts、折叠表达式)在前面章节已经详细展开,这里只做归类速查,不重复展开原理;多线程库(C++11 `<thread>`)详见第 11 章。

## 一、C++11

**`auto` 类型推导 / 基于范围的 for 循环 / `nullptr` / lambda 表达式**

```cpp
#include <iostream>
#include <vector>

int main() {
    auto x = 42;                            // auto:类型推导

    std::vector<int> v{1, 2, 3};
    for (auto& e : v) e *= 2;                 // range-based for:基于范围的 for 循环
    for (auto e : v) std::cout << e << " ";
    std::cout << "\n";

    int* p = nullptr;                          // nullptr:类型安全的空指针字面量,取代 NULL/0
    std::cout << (p == nullptr) << "\n";

    auto add = [](int a, int b) { return a + b; }; // lambda 表达式
    std::cout << add(x, 1) << "\n";
}
```

```
2 4 6
1
43
```

**智能指针 / 右值引用与移动语义**

```cpp
#include <iostream>
#include <memory>
#include <utility>

struct S { std::string data; };

int main() {
    auto p = std::make_unique<S>(S{"hi"}); // 智能指针(unique_ptr),自动管理生命周期
    std::cout << p->data << "\n";

    std::string a = "hello";
    std::string b = std::move(a);            // 右值引用与移动语义:窃取 a 的资源而非拷贝
    std::cout << "b=" << b << " a.empty()=" << a.empty() << "\n";
}
```

```
hi
b=hello a.empty()=1
```

**线程库 / `constexpr`**

```cpp
#include <iostream>
#include <thread>

constexpr int square(int x) { return x * x; } // constexpr:编译期可求值的函数

int main() {
    constexpr int val = square(6);              // 编译期就算好,val 是编译期常量
    std::cout << val << "\n";

    std::thread t([]{ std::cout << "子线程输出\n"; }); // C++11 线程库 <thread>(详见第 11 章)
    t.join();
}
```

```
36
子线程输出
```

C++11 其他重要但本教程已在别处覆盖的特性:右值引用 `T&&`(第 5 章)、`override`/`final`(第 4 章)、`enum class`(第 2 章)、委托构造/继承构造(第 4 章)、可变参数模板(第 3 章)、`static_assert`、`decltype`(第 2 章)、统一初始化 `{}`。

## 二、C++14

**泛型 lambda / 变量模板**

```cpp
#include <iostream>

// 泛型 lambda(C++14):参数用 auto,等价于给 operator() 加模板
auto genericAdd = [](auto a, auto b) { return a + b; };

// 变量模板(C++14):模板化的变量,而不仅仅是函数/类
template<typename T>
constexpr T pi = T(3.14159265358979323846);

int main() {
    std::cout << genericAdd(1, 2) << " " << genericAdd(1.5, 2.5) << "\n";

    std::cout << pi<float> << "\n";
    std::cout << pi<double> << "\n";
}
```


## 三、C++17

**结构化绑定(structured bindings) / `if constexpr` / `std::optional`/`variant`/`any` / 折叠表达式**

```cpp
#include <iostream>
#include <optional>
#include <variant>
#include <any>
#include <map>
#include <string>
#include <vector>

template<typename... Args>
auto sumFold(Args... args) { return (args + ...); } // 折叠表达式(C++17)

std::optional<int> findFirstEven(const std::vector<int>& v) {
    for (int x : v) if (x % 2 == 0) return x;
    return std::nullopt; // 表示“没有找到”,不需要用魔法值或异常
}

int main() {
    std::map<std::string, int> m{{"a", 1}, {"b", 2}};
    for (const auto& [key, value] : m) {   // 结构化绑定:直接解构 pair 的 first/second
        std::cout << key << "=" << value << " ";
    }
    std::cout << "\n";

    auto [x, y] = std::pair{10, 20};        // 也可以解构任意 pair/tuple/聚合体
    std::cout << x << " " << y << "\n";

    if constexpr (sizeof(int) == 4) {         // if constexpr:编译期条件分支,不满足的分支不会被实例化
        std::cout << "int 是 4 字节\n";
    }

    auto r = findFirstEven({1, 3, 5, 6, 7});    // std::optional:可能没有值的值类型
    if (r) std::cout << "找到偶数: " << *r << "\n";

    std::variant<int, std::string> v1 = 42;      // std::variant:类型安全的联合体(带运行时类型追踪)
    v1 = std::string("hello");
    std::cout << std::get<std::string>(v1) << "\n";

    std::any a = 5;                                // std::any:可持有任意类型的值(运行时类型擦除)
    a = std::string("world");
    std::cout << std::any_cast<std::string>(a) << "\n";

    std::cout << sumFold(1, 2, 3, 4) << "\n";        // 折叠表达式
}
```

## 四、C++20

**concepts / ranges / 协程(coroutines) / 模块(modules)**

concepts 详见第 6 章;ranges 详见第 8 章(STL 算法与迭代器)。这里补充协程和模块。

**协程简介**:`co_yield`/`co_await`/`co_return` 让函数可以在中途"暂停"并在之后"恢复",标准库只提供机制(`<coroutine>`),不提供开箱即用的生成器类型,需要用户自己实现一套 `promise_type` "胶水代码"(或使用第三方库如 cppcoro):

```cpp
#include <iostream>
#include <coroutine>

template<typename T>
struct Generator {
    struct promise_type {
        T current_value;
        Generator get_return_object() { return Generator{std::coroutine_handle<promise_type>::from_promise(*this)}; }
        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        std::suspend_always yield_value(T value) { current_value = value; return {}; }
        void return_void() {}
        void unhandled_exception() { std::terminate(); }
    };
    std::coroutine_handle<promise_type> handle;
    explicit Generator(std::coroutine_handle<promise_type> h) : handle(h) {}
    ~Generator() { if (handle) handle.destroy(); }

    bool next() { handle.resume(); return !handle.done(); }
    T value() const { return handle.promise().current_value; }
};

Generator<int> counter(int start, int end) {
    for (int i = start; i <= end; ++i) {
        co_yield i;   // 暂停执行,把 i“产出”给调用者,下次 resume 时从这里继续
    }
}

int main() {
    auto gen = counter(1, 5);
    while (gen.next()) {
        std::cout << gen.value() << " ";
    }
    std::cout << "\n";
}
```

```
1 2 3 4 5
```

**模块简介**:用 `export module`/`import` 替代传统的头文件 + `#include`,理论上能大幅减少重复解析头文件的编译开销,并提供真正的封装(未 `export` 的名字对使用者不可见)。工具链支持仍在完善中,不同编译器/构建系统的实践细节差异较大:

```cpp
// math.cppm —— 模块接口单元
export module math;   // 声明一个名为 math 的模块

export int add(int a, int b) {   // export 导出的名字才能被 import 方使用
    return a + b;
}

int internalHelper() { return 0; } // 未 export,模块外部不可见
```

```cpp
// main.cpp
import math;
#include <iostream>

int main() {
    std::cout << add(2, 3) << "\n";
}
```

在本机 Apple Clang 上的实际构建流程(命名模块目前需要显式的多步构建,尚未像头文件一样"开箱即用"):

```
$ clang++ -std=c++20 -fcxx-modules --precompile math.cppm -o math.pcm
$ clang++ -std=c++20 -fcxx-modules -fmodule-file=math=math.pcm -c main.cpp -o main.o
$ clang++ -std=c++20 -fcxx-modules -c math.pcm -o math.o
$ clang++ math.o main.o -o modules_out && ./modules_out
5
```
