# C++ 教程 · 全面速查手册

> 这套教程的定位和本仓库其他语言教程(`python-tutorial`、`go-tutorial` 等)不同:那几套教程假设读者已经熟悉 C/C++,聚焦"底层到底发生了什么"这种深挖式讲解;**这套 C++ 教程反过来**——假设你已经写过一些 C++ 代码,但知识点比较零散,需要一份**全面覆盖、按知识点组织的速查手册**,把 C++ 这门语言(从基础语法到 C++20)当作一份检查清单过一遍,查漏补缺。因此每一节的讲解**不追求像其他教程那样深挖原理**,而是优先保证**知识点覆盖全**、示例**能编译运行**、内容组织清晰、便于按需查阅。

## 使用建议

- 这不是一套需要从头读到尾的教程,更像一本**按目录查找的工具书**——已经掌握的章节可以跳过,只在需要的时候回来查。
- 每章开头是知识点速览,正文按小节展开,每个知识点配一段**实际编译运行过的** C++ 代码(`g++ -std=c++20`),不确定某个语法的行为时,直接找到对应小节复制代码本地验证。
- 章节末尾统一是 `[← 返回索引](index.md)`,没有强制的上一章/下一章导航——因为本教程定位是速查清单而非线性叙事,鼓励按需跳转而非顺序通读。
