# 面试八股

> "八股文"是中文技术圈对"面试高频概念题"的戏称——不是深度研究，而是**覆盖面广、要能脱口而出**的
> 高频考点整理。本专题综合了 GitHub 上多个 1000+ star 的面试题仓库的共同经验，
> 按语言分成 Python 和 C++ 两套，每套都是"问题 + 简明准确的答案 + 关键代码示例"的密集问答格式。

## 内容

| 语言 | 文件 | 主要覆盖 |
|------|------|---------|
| Python | [python.md](python.md) | 语言特性(装饰器/生成器/元类/GIL/垃圾回收等)、内存管理、并发模型 |
| C++ | [cpp.md](cpp.md) | 语言关键字与OOP、构造析构与拷贝语义、内存管理与智能指针、类型转换、STL、C++11+新特性、多线程 |

## 参考来源

- Python 部分主要参考 [taizilongxu/interview_python](https://github.com/taizilongxu/interview_python)（17k+ star，最经典的中文 Python 面试题仓库），
  并与 [Snailclimb/JavaGuide-Interview](https://github.com/Snailclimb/JavaGuide-Interview)、[lengyue1024/BAT_interviews](https://github.com/lengyue1024/BAT_interviews)、
  [zhengjianglong915/note-of-interview](https://github.com/zhengjianglong915/note-of-interview) 等仓库交叉校对补充。
- C++ 部分主要参考 [huihut/interview](https://github.com/huihut/interview)（38k+ star，最经典的中文 C/C++ 技术面试仓库）
  和 [guaguaupup/cpp_interview](https://github.com/guaguaupup/cpp_interview)，并与其他同类仓库交叉校对。
- 所有代码示例均已本地编译/运行验证，不是照搬摘抄。

> C++ 的 STL 容器/算法/多线程如果想看更系统的讲解（而不是面试问答的密集格式），
> 见 [cpp-tutorial/](../cpp-tutorial/index.md)。
